# El Veci — WhatsApp AI Assistant for Local Businesses

> "Your neighborhood business, always available."

An AI-powered WhatsApp assistant that helps local businesses in Puerto Rico handle customer inquiries, bookings, and information requests — 24/7, without staff.

**Status**: Building in public — Day 19 of 90

---

## What it does

- Answers customer questions automatically via WhatsApp
- Provides business hours, location, services, pricing
- Handles appointment requests and follow-ups
- Responds in Spanish (PR-native)
- Works for any local business: restaurants, repair shops, clinics, salons

---

## Stack

| Layer | Tech |
|-------|------|
| Messaging | Twilio WhatsApp API |
| AI | Claude (via Vercel AI Gateway) |
| Database | Supabase (Postgres) |
| Backend | Node.js / Next.js |
| Hosting | Vercel |
